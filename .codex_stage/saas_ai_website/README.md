# VerityCore AI landing page

Premium static landing page for VerityCore AI, the AI sales assistant and business automation platform from VerityCore Consultancy.

## Production URLs

- Marketing website: `https://ai.veritycore.co.zw/`
- SaaS application: `https://saasai.veritypack.cloud/verityai`
- Create account: `https://saasai.veritypack.cloud/verityai/signup`
- Sign in: `https://saasai.veritypack.cloud/verityai/signin`

## Deployment

Upload the tracked files to the document root for `ai.veritycore.co.zw`.
The Apache configuration redirects obsolete template routes to the canonical
home page and enforces HTTPS.

After deployment, submit `https://ai.veritycore.co.zw/sitemap.xml` in
Google Search Console and request indexing for the canonical home page.
